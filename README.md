
# ⚡ TechXZone — WhatsApp AI Customer Support & Instant Order Bot

TechXZone ই-কমার্স ওয়েবসাইটের (`https://techxzone.shop`) জন্য বিশেষভাবে তৈরি করা একটি উচ্চগতির (Ultra-Fast), প্রোডাকশন-রেডি WhatsApp AI কাস্টমার কেয়ার ও অটোমেটেড অর্ডার বুকিং বট।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Highlights)

- **⚡ অফিসিয়াল Google Gemini AI:** গুগলের নতুন `@google/genai` SDK দিয়ে চালিত। প্রাইমারি মডেল হিসেবে `gemini-3.6-flash` এবং স্বয়ংক্রিয় ব্যাকআপ হিসেবে `gemini-3.5-flash` সংযুক্ত।
- **📲 ডুয়াল WhatsApp পেয়ারিং:** কিউআর কোড স্ক্যান অথবা ৮-ডিজিটের পেয়ারিং কোড দিয়ে লগইন করার সুবিধা।
- **💾 ক্লাউড সেশন রিস্টোর ও ব্যাকআপ:** Render-এর এফিমেরাল (সাময়িক) ডিস্কের সমস্যা দূর করতে প্রতি ৫ মিনিটে সম্পূর্ণ সেশন বান্ডেল আপনার ওয়েবসাইটের বিদ্যমান PHP ডাটাবেজে স্বয়ংক্রিয় ব্যাকআপ নেওয়া হয় এবং সার্ভার রিস্টার্টের সময় তা স্বয়ংক্রিয়ভাবে রিস্টোর হয়।
- **🛒 লাইভ ইন-মেমরি ক্যাটালগ ক্যাশিং:** ক্যাটালগ প্রতি ১৫ মিনিটে সিঙ্ক হয় এবং গ্রাহকের প্রশ্নের সাথে প্রাসঙ্গিক পণ্য ৩-৪টি ফিল্টার করে এআই-তে পাঠানো হয়, ফলে রেসপন্স পাওয়া যায় চোখের পলকে।
- **🔒 ডিটারমিনিস্টিক অর্ডার সিকিউরিটি:** এআই সরাসরি অর্ডার করতে পারে না। ক্যাটালগ প্রাইস, ঢাকার ভিতরের/বাইরের ডেলিভারি চার্জ যাচাই করে গ্রাহকের স্পষ্ট অনুমোদনে পিএইচপি এপিআই-তে অর্ডার পাঠানো হয়।
- **👑 অ্যাডমিন ইনস্ট্যান্ট অ্যালার্ট:** সফল অর্ডারের সাথে সাথে অ্যাডমিনের হোয়াটসঅ্যাপে গ্রাহকের নাম, ফোন, ঠিকানা ও অর্ডার আইডিসহ নোটিফিকেশন পৌঁছে যায়।
- **🎨 প্রিমিয়াম ওয়েব ড্যাশবোর্ড:** ডার্ক নেভি ও এমারেল্ড গ্রিন থিমের লাইভ ড্যাশবোর্ড, যেখান থেকে সরাসরি এআই চ্যাট টেস্ট, ক্যাটালগ রিফ্রেশ ও সেশন রিসেট করা যায়।

## 🚀 রেন্ডার (Render.com) ডিপ্লয়মেন্ট গাইড

1. আপনার গিটহাব একাউন্টে একটি **Private Repository** তৈরি করে প্রজেক্টের সব ফাইল পুশ করুন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for TechXZone WhatsApp Bot"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main

2.  Render Dashboard-এ প্রবেশ করে New + > Web Service সিলেক্ট করুন।
3.  আপনার গিটহাব রিপোজিটরিটি কানেক্ট করুন।
4.  সেটিংস কনফিগার করুন:
      - Name: techxzone-wa-bot
      - Environment: Node
      - Region: Singapore (বাংলাদেশ থেকে দ্রুততম ল্যাটেন্সির জন্য)
      - Branch: main
      - Build Command: npm install
      - Start Command: npm start
5.  নিচের দিকে Environment Variables সেকশনে যান এবং টেবিলে উল্লেখিত ভেরিয়েবলগুলো
    যুক্ত করুন (GEMINI_API_KEY, DASHBOARD_TOKEN, ইত্যাদি)।
6.  Create Web Service বাটনে ক্লিক করুন। ২ মিনিটের মধ্যে সার্ভিসটি বিল্ড হয়ে
    লাইভ ইউআরএল তৈরি হবে (যেমন: https://techxzone-wa-bot.onrender.com)।

📲 WhatsApp পেয়ারিং নির্দেশিকা

পদ্ধতি ১: পেয়ারিং কোড (সবচেয়ে সুবিধাজনক)

1.  ব্রাউজারে আপনার রেন্ডার অ্যাপের ইউআরএল ওপেন করুন।
2.  উপরে "🔑 টোকেন কনফিগার" বাটনে ক্লিক করে আপনার দেওয়া DASHBOARD_TOKEN টি পেস্ট
    করুন।
3.  ড্যাশবোর্ডের "৮-ডিজিটের পেয়ারিং কোড দিয়ে লগইন" বক্সে যে হোয়াটসঅ্যাপ নম্বর
    দিয়ে বট চালাতে চান সেটি আন্তর্জাতিক ফরম্যাটে লিখুন (যেমন: 8801XXXXXXXXX)।
4.  "কোড আনুন" বাটনে ক্লিক করুন। স্ক্রিনে ৮ অক্ষরের কোড আসবে (যেমন: ABCD-1234)।
5.  আপনার ফোনে WhatsApp ওপেন করে Settings > Linked Devices > Link a Device >
    Link with phone number instead অপশনে যান এবং প্রাপ্ত কোডটি টাইপ করুন।
6.  কয়েক সেকেন্ডের মধ্যে ড্যাশবোর্ডে স্ট্যাটাস "কানেক্টেড (Online)" দেখাবে।

পদ্ধতি ২: QR কোড স্ক্যান

1.  ড্যাশবোর্ডে প্রদর্শিত QR কোডটি সরাসরি ফোনের হোয়াটসঅ্যাপ স্ক্যানার দিয়ে
    স্ক্যান করুন।

🧪 এআই মডেল এবং সিস্টেম টেস্ট করার নিয়ম

১. ড্যাশবোর্ড থেকে লাইভ চ্যাট টেস্ট

ড্যাশবোর্ডের ডানপাশের "লাইভ এআই চ্যাট সিমুলেটর"-এ লিখুন:

"T900 Ultra ঘড়ির দাম কত এবং ডেলিভারি চার্জ কত?"

বট চোখের পলকে ক্যাটালগ থেকে সঠিক দাম ও ডেলিভারি চার্জ হিসাব করে মার্জিত বাংলায়
উত্তর দেবে।

২. হোয়াটসঅ্যাপে সরাসরি টেস্ট

বট পেয়ার করা নম্বরে যেকোনো সাধারণ নম্বর থেকে মেসেজ পাঠান:

"ভাইয়া, আমি একটি ঘড়ি কিনতে চাই। ক্যাশ অন ডেলিভারিতে অর্ডার নিবেন?"

বট নিয়ম অনুযায়ী আপনার কাছে নাম ও ঠিকানা চাইবে। নাম ও ঠিকানা পাঠালে সামারি তৈরি
করে কনফার্মেশন চাইবে। "হ্যাঁ" লিখলেই অর্ডার তৈরি হয়ে অ্যাডমিনের কাছে নোটিফিকেশন
পৌঁছে যাবে।

❓ সাধারণ সমস্যা ও সমাধান (Troubleshooting)

1.  AI থেকে কোনো উত্তর আসছে না বা এরর দেখাচ্ছে:

      - নিশ্চিত করুন GEMINI_API_KEY টি সক্রিয় রয়েছে।
      - লগ কনসোলে Timeout বা Quota এরর আছে কি না লক্ষ্য করুন। সার্ভিসটি
        স্বয়ংক্রিয়ভাবে gemini-3.5-flash ফলব্যাকে সুইচ করবে।

2.  রেন্ডার রিস্টার্ট হলে হোয়াটসঅ্যাপ লগআউট হয়ে যায় কি?

      - না! আমাদের বটের সেশন ইঞ্জিন প্রতি ৫ মিনিটে
        https://techxzone.shop/api.php?action=save_settings এ ব্যাকআপ পাঠিয়ে
        দেয়। রেন্ডার রিস্টার্ট হওয়ার সময় restoreSessionFromRemote() ফাংশন
        স্বয়ংক্রিয়ভাবে সেশন রিকভার করে নেয়।

3.  হোয়াটসঅ্যাপ ডিসকানেক্ট দেখালে কী করব?

      - ড্যাশবোর্ডে গিয়ে "⚠️ সম্পূর্ণ সেশন রিসেট" বাটনে ক্লিক করে পুনরায় ফোন
        নম্বর দিয়ে নতুন পেয়ারিং কোড নিন।

### 🔍 প্রোডাকশন রান চেকলিস্ট (Go-Live Checklist)

1. **Google AI Studio API Key:** আপনার নিজস্ব [Google AI Studio](https://aistudio.google.com/) অ্যাকাউন্ট থেকে জেনারেট করা জেমিনাই API Key রেন্ডারের এনভায়রনমেন্ট ভেরিয়েবলে বসিয়েছেন কি না দেখে নিন।
2. **PHP Backend Settings API:** আপনার ওয়েবসাইটের `settings` টেবিলে `wa_full_session_bundle` কি সফলভাবে রিসিভ হচ্ছে কি না তা নিশ্চিত করা হয়েছে। (কোডে ব্যবহৃত রিস্টোর ও ব্যাকআপ ফাংশন স্বয়ংক্রিয়ভাবে ডাটা পাঠায়)।
3. **Admin Alert Phone Number:** `.env` ফাইলে দেওয়া `ADMIN_PHONE` নম্বরটিতে দেশের কোড (যেমন: `8801XXXXXXXXX`) সঠিকভাবে রয়েছে কি না যাচাই করুন।
4. **Instant Fast-Reply:** ক্যাটালগ র‍্যামে ক্যাশ করা থাকায় এবং জেমিনাই এর ফ্ল্যাশ মডেল ব্যবহার করায় প্রতি মেসেজের রিপ্লাই সাধারণত ১ থেকে ২ সেকেন্ডের মধ্যেই তৈরি হয়ে যাবে।
